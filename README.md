# ✨ Happy Birthday, Curly! (Aarvi's Birthday Odyssey) 🎂🎧

An interactive multi-page birthday web application crafted with love for **Aarvi**, affectionately known as **"Curly"** for her iconic curly hair, cute eyes, bright smile, fashion obsession, and eclectic music taste across every genre!

---

## 🚀 How to Run the App
**No installation or build steps required!**

1. Simply double-click [`index.html`](file:///c:/A%20birthday/index.html) to open it in Google Chrome, Safari, Microsoft Edge, or Firefox.
2. It runs smoothly on **desktop, laptops, tablets, and smartphones**.
3. You can also host it with one click on **GitHub Pages**, **Vercel**, or **Netlify** to share the link with Aarvi directly on WhatsApp/iMessage!

## 🎧 "Every Genre FM" Music Player
- **Zero Broken Audio Guarantee:** Uses the browser's native **Web Audio API** to generate real, melodic polyphonic chord progressions, basslines, and music box chimes:
  - *Ch 1: Cozy Acoustic / Indie Pop*
  - *Ch 2: Retro Funk / Lo-Fi Beats*
  - *Ch 3: Y2K Pop / Runway Beat*
  - *Ch 4: Aesthetic Synthwave / Edit Audio*
  - *Ch 5: Dreamy Music Box / Birthday Waltz*
- **Custom MP3 / Audio File Support:** Click **"🎵 Your Song"** on the floating dock to play any MP3/WAV/M4A from your device.
- **Live Visuals:** Spinning vinyl record with Aarvi's photo in the center sticker, real frequency visualizer bars, play/pause, next track, and volume slider!

## ⚙️ Easy Customization
All messages, compliments, snacks, movies, and letters are stored in the clean `CONFIG` object at the top of the `<script>` tag in [`index.html`](file:///c:/A%20birthday/index.html#L705):
```javascript
const CONFIG = {
  recipient: {
    name: "Aarvi",
    nickname: "Curly",
    birthdayMonth: "November 2026",
    salutation: "Dearest Aarvi (Curly) ✨",
  },
  compliments: [ ... ],
  snacks: [ ... ],
  earrings: [ ... ],
  sneakers: [ ... ],
  movies: [ ... ],
  letter: { ... },
  stations: [ ... ]
};
```
Feel free to tweak any text or add personal inside jokes!
